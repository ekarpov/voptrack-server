Scope and download details

Exports use the study reader's current access. A participant's withdrawal can leave pre-withdrawal records available; erasure and account deletion have different effects. Agreement-gap flags use recorded event dates, not verified server receipt times.

Files are prepared privately and served only after generation succeeds. One export can run at a time. If the server is busy, a source is unavailable, or a file reaches a size limit, a download error is returned; retry after resolving the issue. There is no export history or background job queue.

The existing file limits are 1,048,576 records per participant/collection and 4 GiB per export. Exporting selected parts is not available in this first version. Exports are not server backups.
